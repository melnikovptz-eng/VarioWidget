# VARIO Widget

Version: 1.2

iOS WidgetKit project for the VARIO flight instrument.

## Features

- Vertical speed
- Altitude
- Pressure
- Temperature
- Battery
- CLIMB
- LEVEL
- DESCENT
- NO DATA
- LIVE / OFFLINE
- -5 ... +5 m/s gauge
- Small Widget
- Medium Widget

## Files

- VarioWidget.swift
- VarioDataStore.swift
- VarioGauge.swift

## Build

The project is prepared in Termux.

Final iOS compilation requires macOS + Xcode.

If XcodeGen is installed on the Mac:

    xcodegen generate

Then open:

    VarioWidget.xcodeproj
